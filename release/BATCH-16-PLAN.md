# 第十六批：时间线搜索入口与大字体说明

日期：2026-11-14（Asia/Tokyo）。起点4e931fdf8818a9b3522fad505d350499cc7b218d。沿用feat/native-manual-entry和草稿PR；不签名、不上传Apple、不合并main。保留既有未跟踪design目录，不引入模型服务或依赖。

## 问题、架构与影响

第十五批原图确认：最大辅助字号下中英文搜索提示省略，默认字号中文提示也省略。现有MomentTimelineView负责本机记录筛选、日期分组、原生searchable状态；MomentStore负责加载，RootView持有各标签导航。搜索范围为日期、类型、感受和标签，不搜索私密备注。将完整范围塞入原生搜索框不能保证各设备字号可读。

本批采用局部改动：原生搜索框改为简短Search moments／搜索记录；原有范围说明移为可自然换行、支持Dynamic Type的正文提示。保留既有搜索语义、枚举、记录内容、原生键盘和清除筛选行为。影响仅时间线视图、本地化及既有图库用例中的搜索检查，不重写导航、存储或设计体系。

用户选中的“沉浸扉页”记录为后续整体视觉方向。本批没有完成该提案的原生视觉实现，也不以搜索可用性验收代替审美认可。系统窗口缩放、终止恢复策略和性能基线仍是后续独立任务；避免为了未验证的环境现象修改生产架构。

## 风险与验证边界

- iOS原生搜索框的系统布局与可访问性树在手机／iPad／辅助字号下可能不同；用实际可见控件与窗口几何核对，不依靠字符串长度推断不截断。
- 正文说明可滚动、可换行；不要求长页面所有内容同屏，也不通过固定高度或缩小字体隐藏问题。
- 双语界面验证使用合成ASCII查询，不冒充中文IME组合或候选输入验收。备注不在既有搜索范围，说明不能误导用户。
- 保留原始发行占位、真机、其他运行时、窗口缩放、终止恢复和整体视觉质量边界。
