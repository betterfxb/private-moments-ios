# 原生UI体系：Rose／玫瑰

本体系是我方选择，不是DO精确Token。目标：明亮、清楚、柔和而有识别度；通过鲜明主题、紧凑信息与柔和表面建立亲近感，避免棕色滤镜、通篇大字或通篇淡粉。

## 核心框架

1. Foundations：语义颜色、系统字体、8/12/16/20/24间距、16/22圆角。
2. Surfaces：暖白页面、实色分组表面、浅玫瑰强调表面、深色专属计时背景；分隔线与克制投影表达高度。
3. Components：BrandHeader、WeekSelector、MomentRow、SectionHeading、Primary/SecondaryAction、选择胶囊、详情摘要、空状态、错误卡；适配大字号。
4. Patterns：首页“品牌→一周→操作→记录→概览”；时间线“筛选→记录”；详情“日期→类型与时长→感受与评分→标签／私密笔记→编辑／删除”；编辑器按填写任务分组。
5. States：空／选中／按下／禁用／错误／保存失败／失活遮罩，均保留文案或图标，不仅靠颜色区分。

## 字体与布局

系统语义字体，普通字号品牌使用工具栏title2/bold rounded；辅助字号品牌进入内容区，以title/bold自然换行。页面title2/semibold；分组headline/semibold；记录headline；正文body/subheadline；元数据caption。不使用超大衬线口号。数值使用monospacedDigit；不缩小辅助字号以通过截图。页边20，容器内16，分组间24。iPhone以内容自适应布局；iPad使用居中最大宽度700，避免横跨全屏。字号布局使用系统Dynamic Type，辅助字号行转纵向；固定图标容器使用明确装饰尺寸，大字号隐藏冗余类型图标。

## 组件与交互

- MomentRow：真实类型的SF Symbol→类型／感受→时长与时间→评分与已有笔记锁定线索；不显示私密笔记正文。整行打开详情，组合辅助阅读。
- WeekSelector：星期＋日期＋有记录的小点；选中实色、今天描边；最小44pt高。辅助字号改为可展开的系统周日期菜单，避免大字体被压成纵向日期；菜单提供完整日期与真实记录数。
- 操作：计时为主，补记为次；普通字号并列，辅助字号纵排。按钮保持44pt触控高度、完整换行标签，点击反馈遵守Reduce Motion。
- 内容表面：实色白／深灰和极轻边线；不把普通白卡称为玻璃。导航材质由系统处理；不自绘假Liquid Glass。
- 编辑：保留日期确认面板、分钟／秒、标签、取消确认与保存错误。感受选项增加SF Symbol和选中勾选语义；不使用虚构的健康／关系数据。
- 详情摘要：并列卡片按最高内容确定行高并顶端对齐，保留完整翻译；辅助字号转纵排。数字输入复用JournalInput软表面和44pt最小高度。
- 可访问性：遵守减少透明度／动效，字段与保存控件可滚动到达；保留现有隐私遮罩和VoiceOver标签。截图与对比测试不等于真机VoiceOver合规。

## 视觉验收

必须查看原生Today（空／保存后）、Recap、Session、Timeline、Detail、Settings及最大字号控件；对比同一配置的上一批截图。检查主题一致性、标题比例、信息层级、边界、系统条遮挡、深色对比与可达性。DO商店图含透视与不同内容，只比较可见设计关系，不声称像素级胜出。
