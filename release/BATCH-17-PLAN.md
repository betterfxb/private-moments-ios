# 第十七批：键盘下的搜索结果与可滚动反馈

日期：2026-11-15（Asia/Tokyo）。起点0613df6571e5ce04eb42b0a9a5fe5269003ce1a8，最近完整受测82ccfcc；沿用feat/native-manual-entry和草稿PR。design目录保持未跟踪，不签名、不上传Apple、不合并main。

## 问题、架构和范围

第十六批实际原图显示，SE最大辅助字号搜索的筛选及范围说明排在结果数之前，软件键盘遮挡计数下缘；小屏空结果说明也在键盘下方。Settings的brief备份反馈位于ScrollView外，最大字号约占44%屏幕高度，取消后删除目标曾需7次普通与5次停稳拖动。测试通过没有消除这些实际操作成本。

MomentTimelineView本地状态负责原生searchable、查询和类型筛选，MomentStore提供记录；SettingsView负责备份UI状态和系统文件回调，实际读写及事务独立。仅调整两处页面布局和实际交互检查，保留Dynamic Type、完整提示、44点关闭操作、私密备注搜索排除、文件确认与精确数据断言，不改存储、认证或文件提供方，不重写整体视觉体系。

采用Apple支持的[搜索激活与提交](https://developer.apple.com/documentation/swiftui/managing-search-interface-activation)、[滚动读取器](https://developer.apple.com/documentation/swiftui/scrollviewreader)与[交互式收键盘](https://developer.apple.com/documentation/swiftui/view/scrolldismisseskeyboard(_:))。搜索激活时结果先于辅助筛选和说明，空结果省去装饰占位；提交后收起键盘、保留查询与结果必须实际验证。Settings brief反馈进入滚动正文顶端，结果出现时由应用滚到顶端，之后正常滚动可将其移出，不自动超时、不截断或缩小字体。错误及重选恢复提示保留原位置与动作。

## 风险和边界

- 原生搜索取消／提交语义不同，必须断言真实提交后查询及匹配数没有丢失；不以清空查询冒充完成搜索。
- 最大字号不能保证一屏容纳所有正文。要求正在输入的计数完整无遮挡，并提供真实提交／正常滚动阅读后续说明的路径，不缩小字体或隐藏必需信息。
- 反馈从固定区改到正文可能影响出现时的位置、系统sheet关闭时机、关闭后的滚动及旧测试；保留无需测试滚动的完整可见断言与取消后数据未变断言。
- 不预设固定滚动次数，按原图几何及真实拖动记录比较。反馈不再挤压视口是目标；完整设置页本身长度不宣称已全部消除。
- 无新增模型依赖、持久化格式或数据迁移；沉浸扉页仍是后续视觉提案。中文IME、真实窗口缩放、终止恢复、真机和发行配置保持独立待办。
