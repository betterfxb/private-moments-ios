# 第十一批：iPad 最大辅助字号补充验收

日期：2026-11-13（Asia/Tokyo）。承接第十批已通过的四配置结果，补齐此前明确未验证的 iPad 最大辅助字号竖屏。继续保留现有草稿 PR，不签名、不上传 Apple、不合并 main；未跟踪的 design 目录不纳入本批。

## 问题、架构与修改方案

第十批的 iPad 仅验证 Large；小屏最大辅助字号通过不能代替 iPad。Today、Recap、Timeline、Detail、Settings 依赖系统 Dynamic Type 与尺寸类别，各自已有滚动及大字体布局；iPad 顶部 Tab、宽屏键盘和纵向大字体的组合需要独立运行与原图核对，不能凭代码推断通过。

验证数据流为工作流输入 → Python 矩阵 → 系统模拟器字号 → verify-mac.sh 的既有 input-only 分支 → testScreenGallery 的中英文真实操作及截图。新配置仅开放给显式 input 范围，保持现有 full 四配置、backup 范围、App／Domain／存储／备份／认证及 UI 方法不变。验证脚本使用标准库，不增加依赖。只有新原图或断言确认产品问题时才作局部修复，且记录原因并重新验证受影响范围。

## 风险与范围边界

- 新配置使用既有 input-only 图库：包括真实数字／ASCII 多行备注、继续编辑／丢弃、计时、保存失败恢复、筛选、详情、设置与认证请求后的系统应用切换。不是实际系统文件导入导出回路，也不重复声称执行 50 单元或 Release 排除检查。
- 不强求全部表单与键盘同屏，不缩小系统字体；关键文字与操作通过实际滚动可达。宽屏不能套用手机底部 Tab 边界。
- 云端执行时间包含服务启动、检查及截图导出，不能作为产品性能数据。启动前平台失败与功能失败分别记录，只读网络恢复不冒充测试重跑。
- 真机 VoiceOver／Switch Control、中文 IME、成功认证、待决认证取消、iPad 横屏／分屏、旧系统、进程终止恢复和大备份性能仍需独立工作，不在本批扩大结论。
