## 两次失败与键盘断言修正

首次 [43410423992](https://github.com/betterfxb/private-moments-ios/actions/runs/43410423992)，源码 `86674c9`，1项 UI 在109.270秒失败。分钟录入后，单次 Done 的 `keyboard.exists` 五秒消失检查未完成。5张阶段 PNG 已下载，实际打开 Today／时长两张；校验录屏后实际查看98／104／106秒三帧，后两帧软键盘已隐藏。该次仍记失败，不凭录屏推断焦点已离开。

第二次 [43414522526](https://github.com/betterfxb/private-moments-ios/actions/runs/43414522526)，源码 `ee49eee`，保留原通过条件，补失败几何、层级与物理图。1项 UI 在144.777秒失败，6 PNG＋1层级已下载；实际打开失败原图并阅读层级。键盘 `exists=true`、`hittable=false`，frame=(0,1307,1032,69)，真实按键从 y=1381 开始，超过窗口底1376。物理图显示软键盘隐藏，底部仍有浮动工具按钮；字段仍有 AX Keyboard Focused 标记，因此不能宣称焦点清除。

Apple 的 `isHittable` 反映当前能否接收点击；元素离屏或被覆盖等情况可返回 false，AX 节点存在与键盘在屏幕可操作不是同一事实。[Apple 官方说明](https://developer.apple.com/documentation/xcuiautomation/xcuielement/ishittable)

最终仅修正 UI 检查：真实输入后、点击前要求键盘存在且可操作；单次真实 Done 后，在原五秒内等待键盘不存在或不可操作，同时要求无 alert，避免把弹窗遮挡当收键盘。原本地化、44 pt触点、精确草稿、继续编辑及真实丢弃检查保持，失败仍留图和层级。没有重试点击、延长等待或修改应用。

最终日志中英文各两次输入后收键盘检查，对应数字及多行备注；每种语言各一次真实 Settings 前台切换及完整锁定标题／状态检查。当前证据证明软键盘可见性及后续连续操作，**不证明 AX 焦点或 FocusState 已离开**。[FocusState 官方语义](https://developer.apple.com/documentation/swiftui/focusstate/)与本次能直接观察的结果须分开。

## 剩余问题与后续建议

本批按范围完成不代表整个产品开发完成。建议依次推进：

1. 真机中文IME组合／候选、多行长文本、VoiceOver／Switch Control、外接及浮动键盘；同时验证焦点和滚动发现性。
2. iPad横屏、分屏、深色最大字号、中间字号及旧系统，按实测问题局部修复。
3. 真机成功Face ID／Touch ID、待决认证取消、锁屏保护，系统终止后的计时／草稿恢复与大数据性能。
4. 单独开展视觉品质评审与用户认可；功能通过不能替代审美判断。

模拟器认证可能在切换前已失败，故只证明请求后后台与返回状态，不证明待决认证取消或解锁成功。双语界面使用ASCII合成多行输入，不证明中文IME。外部文件源、中文完整系统文件回路及分发仍待独立验收。既有发布者、Bundle ID、隐私政策和审查联系占位未处理，继续先开发后上线；没有签名、TestFlight上传或main合并。
